# ⚡ NostrPix — Bitcoin Lightning & Pix Acessível

Aplicativo móvel acessível que integra pagamentos **Bitcoin Lightning Network** via **Nostr Wallet Connect (NIP-47)** e **Pix BRCode (EMVCo)**.

---

## 🚀 Como Baixar o APK

1. Vá na aba **[Releases](../../releases)** deste repositório no GitHub.
2. Baixe o arquivo **`NostrPix.apk`**.
3. Abra e instale diretamente no seu celular Android.

---

## 🛠️ Tecnologias Utilizadas
- **Capacitor.js 6**: Empacotamento Android nativo.
- **Nostr-tools 2.7.0**: Conexão NWC (NIP-47 / NIP-04 / NIP-19) com carteiras Lightning (Alby, Mutiny, Umbrel, Coinos).
- **jsQR**: Leitura de QR Codes Lightning e Pix via câmera nativa.
- **Tailwind CSS & FontAwesome 6**: Interface moderna e de alto contraste.
- **GitHub Actions**: Compilação automática e contínua do arquivo `.apk`.
